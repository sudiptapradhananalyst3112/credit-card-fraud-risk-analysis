# Credit Card Fraud Risk Analysis Dashboard

## 📊 Project Overview
This project is an interactive data analytics dashboard designed to monitor, track, and analyze credit card fraud risks. It helps fraud prevention teams pinpoint high-risk transaction types, geographic hotspots, and temporal trends to mitigate financial losses.

## 💡 Key Insights & Features
- **KPI Metrics:** Tracked overall Fraud Rate (28.60%), total Fraudulent Transactions (286), and Critical Risk Transactions (10.70%).
- **Fraud Type Analysis:** Identified 'Card Not Present' as a top driving fraud category.
- **Geographic Hotspots:** Bar chart breakdown tracking high-volume fraudulent states, led by Maharashtra and Karnataka.
- **Temporal Trends:** A line chart showing monthly fluctuations with distinct spikes toward the end of the year (December).
- **Interactive Filters:** Side panel allows deep-dives by Fraud Type, State, and specific Merchant Names (Amazon India, Flipkart, etc.).

## 🛠️ Tools Used
- **Power BI / Desktop** (Dashboard Design & DAX Modeling)
- **Power Query** (Data Cleaning & Transformation)
